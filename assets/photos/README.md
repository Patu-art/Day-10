# Real venue photography integration

This demo uses original vector illustrations rather than pretending that stock images show the real Kiku venue. To create an owner-approved final version, request original, licensed images of:

- Kiku's actual interior with speakers, natural materials and seating (hero)
- The actual coffee/pastries and counter (day section)
- The record system, DJ equipment and listening space (night/sound section)
- Exterior and a clear logo file, if available

Suggested filenames: `kiku-hero.webp`, `kiku-coffee.webp`, `kiku-sound.webp`, `kiku-exterior.webp`, `kiku-logo.svg`. These do not exist yet and the site does not reference them. Replace SVGs and alt text only when approved source files are available.
